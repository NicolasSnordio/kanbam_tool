# Kanbam Tool

Um quadro Kanban pessoal, bonito e direto ao ponto, criado para organizar demandas de desenvolvimento sem adicionar mais complexidade ao trabalho.

## Funcionalidades

- Quadro com Backlog, Próximas, Em andamento e Concluídas
- Agenda mensal com tarefas organizadas por prazo
- Criação de tarefas diretamente em um dia do calendário
- Arrastar e soltar tarefas entre colunas
- Criação, edição e exclusão de tarefas
- Busca e filtro por prioridade
- Persistência local no navegador
- Interface responsiva com animações sutis

## Stack

- React + Vite
- Tailwind CSS
- Anime.js
- Lucide React

## Executando localmente

```bash
npm install
npm run dev
```

Para gerar uma versão de produção:

```bash
npm run build
```
